# Cloud-Based File Storage System

A Python + AWS S3 project for secure cloud file management.

## What This Does
- Upload, download, and delete files from AWS S3
- IAM role-based access control for multi-user security
- Automated file operations using Python (boto3)

## Tech Stack
- AWS S3 (object storage)
- AWS IAM (permissions & access control)
- Python 3 + boto3 library

## How to Run
1. Install boto3: `pip install boto3`
2. Configure AWS credentials
3. Run `python main.py`
